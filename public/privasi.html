Kebijakan Privasi

Kebijakan ini menjelaskan data apa yang dikumpulkan [NAMA USAHA / NAMA PEMILIK] (“kami”) saat kamu memakai Toko Token, dan bagaimana data itu dipakai, sesuai UU No. 27 Tahun 2022 tentang Pelindungan Data Pribadi.

1. Data yang kami kumpulkan

  • Data akun: nama, email, dan password (disimpan dalam bentuk hash, tidak bisa dibaca).
  • Data transaksi: nominal, waktu, metode, dan status pembayaran dari Midtrans. Kami tidak menyimpan nomor kartu atau data rekening.
  • Data pemakaian: waktu request, model, jumlah token, biaya, dan status. Isi prompt dan jawaban tidak kami simpan di database kami.
  • Data teknis: alamat IP dan user agent saat login, untuk keamanan akun.

2. Pemrosesan oleh pihak ketiga

Isi request diteruskan ke penyedia model AI yang kamu pilih untuk diproses. Pembayaran diproses oleh Midtrans. Masing-masing pihak tunduk pada kebijakan privasinya sendiri. Jangan kirim data sensitif yang tidak boleh diproses pihak ketiga.

3. Penggunaan data

Data dipakai untuk menjalankan Layanan, menagih pemakaian, mencegah penyalahgunaan, mengirim email terkait akun (mis. reset password), dan memenuhi kewajiban hukum. Kami tidak menjual data pribadimu.

4. Penyimpanan & keamanan

Data disimpan selama akun aktif dan selama diwajibkan oleh peraturan (mis. catatan transaksi). Kami memakai enkripsi koneksi (HTTPS), hash password, dan pembatasan akses.

5. Hak kamu

Kamu berhak meminta salinan, koreksi, atau penghapusan data pribadimu dengan menghubungi kami lewat halaman kontak.
