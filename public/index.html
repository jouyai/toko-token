No. 003 — Cara Kerja

Tiga langkah. Lebih cepet dari antri di minimarket.

  1. 01

    Daftar & isi saldo

    Top up mulai dari nominal kecil buat nyoba, atau borongan buat produksi. Bebas.

  2. 02

    Scan QRIS

    Bayar dari e-wallet atau m-banking apa aja. Saldo masuk otomatis begitu pembayaran terkonfirmasi.

  3. 03

    Pakai API key

    Bikin API key di dashboard. Satu endpoint, format kompatibel OpenAI, semua model.

No. 005 — Tanya Jawab

      
Yang sering ditanyain.

    

    

      
Token itu apa sih?
Potongan teks yang dibaca dan ditulis model. Kira-kira 1 token ≈ 3–4 huruf. 1 juta token kurang lebih setara 1.500 halaman teks.

      
Saldo bisa hangus?
Nggak. Saldo tetap ada selama akun kamu aktif.

      
Bisa dipakai buat banyak model?
Bisa. Saldo kamu satu dompet Rupiah; tiap request dipotong sesuai tarif model yang dipanggil dan jumlah token yang terpakai.

      
Kalau request gagal, saldo tetap kepotong?
Nggak. Request yang gagal di sisi server model nggak ditagih.

      
Bayarnya pakai apa?
QRIS (semua e-wallet & m-banking), GoPay, ShopeePay, dan Virtual Account bank. Diproses oleh Midtrans.
